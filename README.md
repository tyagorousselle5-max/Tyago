# 🛍️ Tyago Shop - Site E-commerce Gratuit

Un site e-commerce moderne et gratuit créé avec HTML, CSS et JavaScript pur.

## ✨ Fonctionnalités

- ✅ **Design moderne et responsive** - Fonctionne sur tous les appareils
- ✅ **Système de panier** - Ajoutez/supprimez des produits
- ✅ **Stockage local** - Les données du panier sont sauvegardées
- ✅ **Section produits** - Affichage dynamique des articles
- ✅ **Formulaire de contact** - Recevez des messages de clients
- ✅ **Interface conviviale** - Navigation fluide et intuitive
- ✅ **Entièrement gratuit** - Sans frais d'hébergement ou d'abonnement

## 📂 Structure du Projet

```
├── index.html      # Page principale
├── styles.css      # Styles CSS
├── script.js       # Logique JavaScript
└── README.md       # Documentation
```

## 🚀 Déploiement Gratuit

### Option 1: GitHub Pages
1. Allez dans **Settings** de votre dépôt
2. Activez **GitHub Pages** depuis la branche `main`
3. Votre site est en ligne à `https://tyagorousselle5-max.github.io/Tyago`

### Option 2: Netlify
1. Connectez-vous à [Netlify](https://netlify.com)
2. Drag & drop votre dossier ou connectez votre dépôt GitHub
3. Votre site est automatiquement déployé

### Option 3: Vercel
1. Connectez-vous à [Vercel](https://vercel.com)
2. Importez votre dépôt GitHub
3. Cliquez sur "Deploy"

## 📦 Ajouter vos Produits

Modifiez le tableau `products` dans `script.js` :

```javascript
const products = [
    { id: 1, name: 'Mon Produit', price: 29.99, emoji: '🛒', description: 'Description' },
    // Ajoutez d'autres produits...
];
```

## 🎨 Personnalisation

- **Couleurs**: Modifiez les codes couleur dans `styles.css`
- **Logo**: Changez "Tyago Shop" dans `index.html`
- **Contenu**: Éditez le texte selon vos besoins
