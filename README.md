## 🎨 Design et Personnalisation

### Couleurs
- **Primaire**: #667eea (Violet)
- **Secondaire**: #764ba2 (Violet foncé)
- **Accent**: #ff6b6b (Rose/Rouge)

### Modifier les Couleurs
Éditez les variables CSS dans `styles.css`:
```css
:root {
    --primary: #667eea;
    --secondary: #764ba2;
    --accent: #ff6b6b;
}
```

### Modifier les Produits
Éditez le tableau dans `script.js`:
```javascript
const products = [
    { 
        id: 1, 
        name: 'Votre Produit', 
        price: 99.99, 
        image: 'url_image',
        description: 'Description' 
    }
];
```
